# 老板生日/周年关怀自动生成与推送系统 — 设计文档

日期：2026-10-26
项目目录：`D:\deepseek_space\boss-greeting`

## 1. 背景与目标

公司每月需要向入驻企业老板发送生日、成立周年、入园周年祝福（文案 + 海报）。
目前流程人工整理，现改为自动化：

- 每天上午 10:00（Asia/Shanghai）自动匹配当天"过节点"的老板
- 按模板生成祝福文案
- 将姓名/文案/落款合成到海报背景图上生成海报
- 通过企业微信应用单发给指定同事，由其审核后手动转发
- 部署在云服务器上运行

## 3. 数据层

沿用现有 Excel 字段（来源：2025年9月样例）：

| 字段 | 说明 | 示例 |
|---|---|---|
| 类别 | 三种节点：企业家生日 / 企业成立周年庆 / 企业入园时间 | 企业家生日 |
| 企业名称 | — | 东莞市杨辰新材料有限公司 |
| 所属项目 | 园区名，用于海报落款（可能多个，取其一） | 联科滨海智造港 |
| 姓名（企业实际控制人） | 外文姓名走英文模板 | 王某 |
| 职务 | — | 执行董事 |
| 性别 | 男/女，用于"先生/女士"称谓 | 男 |
| 日期 | 生日：出生年月日；成立周年：企业创立时间；入园周年：企业入园时间（格式混杂，需兼容 `2023-9-12`、`2001/9/14` 等） | 1979-09-02 |

匹配规则：
- 三种类型各自独立匹配；当天日期的 MM-DD 与记录日期的 MM-DD 相同即命中
- 成立周年 / 入园周年按 `当年 − 起始年份` 计算周年数（如 2013 年成立，2025 年即 12 周年）
- 命中记录按"所属项目"归组，便于一天内按园区打包推送

三种模板（取自 2025 年 9 月实际文案，正文固定，仅替换变量）：

- 生日：`尊敬的 {姓名} {称谓}：` + 生日祝福正文 + `{项目落款} 敬上`
- 成立周年：正文含 `值贵司成立{周年数}周年之际`
- 入园周年：正文含 `祝贵司入园{周年数}周年快乐`
- 外文姓名（含字母）使用英文模板 `Dear {称谓}.{姓名},`（具体措辞以清单为准）
首次交付时把 `2025年9月` 目录两个 Excel 的三种类型共 44 条记录整理进台账。

## 4. 文案生成

`templates/文案模板.yaml`，三种类型各一套正文模板，与现有文案逐字一致，示例（生日）：

```
尊敬的 {姓名}{称谓}：

何其幸运，年岁并进
在这特别的日子里
愿您常怀希望与炙热，执着追求成就锦绣韶华
前路浩浩荡荡，万物皆可期盼
祝您生日快乐！岁岁安澜！

{项目落款} 敬上
```

占位符：`{姓名}` `{称谓}`（先生/女士）`{项目落款}` `{周年数}`（周年类）。
同时准备三张空白背景图（生日 / 成立周年 / 入园周年各一，海报措辞有差异）。

## 5. 海报合成

- 输入：空白背景图（1080×2400 左右，待用户提供；未提供前先从样例海报抹除文字自制底图）
- Pillow 按"姓名称谓（粗体大字）→ 祝福文案（多行居中）→ 黄色短分隔线 → 落款"排版
- 输出：`output/YYYY-MM-DD/项目-类别-MMDD-姓名.jpg`，命名规则与现有一致

## 6. 企业微信推送

- 优先：企微自建应用单发（access_token → 上传临时图片素材 media_id → 发送 image + text 消息）
- 凭据：`config.yaml` 中的 corpid / secret / agentid / 收件人账号
- 降级：配置开关切到群机器人 webhook（markdown 文案 + 图片）
- secret 不入库：config.yaml 加入 .gitignore，提供 config.example.yaml

## 7. 可靠性

- 每次运行写 `logs/YYYY-MM-DD.log`：命中名单、生成结果、推送结果
- 推送失败自动重试 1 次，仍失败则日志记录错误并以非零码退出
- 记录已发送键（日期+姓名+类别），同日重跑不重复发送
- 当天无命中：静默正常退出

## 8. 部署与运行

- 云服务器 cron：`0 10 * * *`（服务器为北京时间；否则用 CRON_TZ=Asia/Shanghai）
- 命令：`python -m src.main --config config.yaml`
- 支持参数 `--dry-run`（只生成不推送）和 `--date YYYY-MM-DD`（补发/调试指定日期）

## 9. 测试

- roster：日期匹配、周年数计算、闰年 2/29 处理
- copywriting：称谓/占位符渲染
- poster：排版输出非空且尺寸正确
- wecom：mock HTTP，验证消息体结构与重试
