如何用 AI 对话制作一套自动推送系统

从需求描述到生产上线，全程通过自然语言对话完成，不需要写一行代码

1
需求梳理
用大白话描述你要做什么，AI 会追问关键细节直到需求清晰。
我只说了一句："我准备做一个新项目，每天根据生日的老板生成模板文案和海报，推送给指定的人"。
AI 追问了：数据格式？推送到哪？谁接收？定时时间？——每个回答一轮对话就搞定。
↓
2
设计方案确认
AI 给出架构方案 + 技术选型，我确认后它写设计文档存档。
Excel 台账→ Python 脚本→ 模板文案→ Pillow 海报→ 钉钉推送
↓
3
数据准备
把现有的 Excel 丢给 AI，它写解析脚本自动导入台账、处理格式差异、去重、跳过坏行。
联科给的原始表格很乱（生日用 Excel 序列号、有的只写了"阳历11.16"、同一人多行重复），
AI 写了 80 行脚本一次性解决，我只需要说 "把联科的数据录进去"。
↓
4
核心功能迭代
每说一个需求，AI 就实现一个功能并部署。全程我做的事只有：提需求、看结果、说"可以"或"不对"。
模板文案
粘贴一段话给 AI，它写成 JSON 模板
按园区路由
"联科发给龙银燕"→ 自动配好
抄送验收
"推送同步给我"→ 加 cc 机制
每周推送
"改成每周五推下周"→ 改 cron
↓
5
管理后台
一句话："做一个管理配置前端，可以向我提问"——AI 问了 4 个问题（功能范围/技术形态/登录方式/视觉风格），然后直接交付 6 页面的后台。
仪表盘台账管理模板编辑推送配置发送记录手动运行
零第三方依赖，纯 Python 标准库 HTTP 服务 + 原生 JS 单页。有 bug AI 自己截图定位修复。
↓
6
测试与部署
AI 自己写测试用例并跑通；部署到服务器、配 crontab、验证端到端推送，全程不需要人工介入。
最终测试结果：单元 7/7 · API 24/24 · 浏览器 UI 模拟 13/13 全过。
部署 = AI 写好代码 → scp 到服务器 → 跑一遍 dry-run 确认 → 真实推送验证 → 改 crontab → 收工。
↓
7
持续维护
上线后的日常操作全部通过对话或管理后台完成：
换负责人 → 后台改个手机号
新园区接入 → 发我数据文件 + 后台加一行路由
改文案 → 后台模板页直接编辑保存
补发某天 → 后台手动运行页选日期点推送
实际对话提示词示例（我说的原话）：

"我准备做一个新项目，大致流程如下：①我给你以往的数据 ②每天10点根据生日生成模板文案和海报发给指定的人 ③指定的人再手动发送"

"把后台企业家的相关数据清除，换成联科的数据。后续其他产业园会相继把数据交给我。针对不同的园区，设置不同的负责人"

"所有的推送都要同步给我的账号，作为一次推送，这样我可以检查是否推送成功"

"每周五推送下周一至下周日的，说一下你的计划"

"做一个管理配置的前端，你可以向我提问来考虑有哪些页面和功能"

"帮我配置一下 联科是龙银燕"
